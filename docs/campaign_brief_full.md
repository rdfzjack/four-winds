# 个人主线：给讨论用的规则框架

整份贴给讨论用的 AI 即可，不用另附文件。这里只写游戏**能做什么**、每关**要填什么**，剧情、基调、叙事长短都由作者决定，这份文档不替作者定。

## 一、规则框架

**游戏**：大富翁式桌游，2 个以上玩家轮流掷骰走格子，买地、收租、盖房、交易，破产出局。单位万圆。个人主线 = 每个角色一条，每条若干关，每关一张地图、一组对手、一组胜负条件。

**角色**（4 个，可当玩家也可当对手）：斐斐（史德斐）、小九（葛乔玖）、孔雀（杜玛瑟）、理理（任厄理）。对手用带性格的角色 AI。超过 4 个座位时，多出来的是“路人”。路人有没有性格、怎么打、有没有台词、在剧情里是什么意义，由作者按剧情定。系统上两种都行：用没有性格的标准 AI，或者给他一组自己的 AI 参数（和 4 个角色是同一种参数表）。路人名单由作者给。

**一关里能定的东西**

1. 地图：从下面的地图目录里选一张。
2. 座位：玩家是哪个角色；每个对手是谁（角色或路人）；每个座位的开局现金、存款。
3. 预置地产：开局谁已经有哪几块地、哪些房子、哪些企业（不写就是都没有）。
4. 胜利条件、失败条件：各是一个列表，**满足任意一条就结束**；同时满足时算失败。
5. 限时（**可选，不是每关都有**）：按天数的一种失败条件（一天 = 所有人各走一次），“一个月”暂定 30 天。原版 20 个战役关里，只有 5 关有限时（一个月 3 关、三个月 2 关），多是“冲刺型”目标；其余关的失败条件只有破产，或指定的人破产 / 没有首先达成目标。

**条件类型**（目标只能从这里选；要别的要先说，工程上要加）

| 类型 | 意思 |
|---|---|
| 某人破产 | 指定某个对手，或“所有对手全部破产”（= 击败所有对手），或“任意一个” |
| 建成某种房子 | 谁、哪种房子（平房 / 旅社 / 旅馆 / 小洋楼 / 花园洋房 / 别墅）、几栋。写成别人建成就是失败条件，即“首先建成” |
| 控制某行业全部企业 | 行业见地图目录 |
| 凑齐一条街 | 指定街，或任意一条 |
| 拥有全图 N% 以上的地 | |
| 总资产达到 N | |
| 天数超过 N | 限时用，可有可无 |

玩家破产默认是失败条件之一。**暂时没有**：保护同伴不破产、联盟 / 背叛、关卡进行中的剧情事件和特殊台词。

**难度只能靠这些调**：对手是谁和几个、开局资金（含让某个对手多一点）、预置地产、限时、地图大小。

**叙事能放的位置**（关卡进行中没有叙事）

- 每关：关前、胜利后、失败后。
- 形式：一段文字，或逐句对话。对话每句是 `说话人：内容`，句尾可加 `[表情]`（平常 / 开心 / 生气 / 得意 / 沮丧 / 惊讶 / 无奈），说话人是角色、路人名字或“旁白”。
- 长度：目前不设限，界面还没做，以后按显示效果调整。
- 主线通关后的收尾：目前没有位置，需要的话说一声，工程上加。

**三位主角在战役里各自要做什么**（整理自原版战役的关前叙述、对话和结局文字；各关的先后以下面“原版战役”表为准，文字没写明的我没有补）：

- **四毛**（流浪儿，拾荒得古董后想置地安家）
  - 起点：在金县被豪绅金如山欺其年幼、排挤盘剥，只想购地造屋 → 第 1、2 关“建起一所旅馆”“让金如山破产”。
  - 去银城：听说银城水运发达，想控制水运 → “控制所有码头”；银城的码头被外商发达而垄断、提高泊价，他与董莺雨组成民族商业联盟，联手挤垮发达而，夺回码头，并保证董莺雨不破产。
  - 去上海：整垮发达而（他在中国的发家之地是上海），在上海滩与冯全篾谈“各有各的地盘，不可越界”，最后称霸上海 → “三个月击败发达而”“击败所有对手”。
  - 结局：“由一个流浪儿发展成为上海滩商业巨子，从此扶危济贫、扶助民族工业，成为中国商界的骄傲。”
- **冯全篾**（元宝山黑帮老大，豪爽、喜欢经营投资）
  - 起点：想扩大势力去金县投资，被金如山的地价挡住，怒而要整倒金如山 → “击败金如山”；回元宝山发现洋行买办包德利、洋人发达而抢了生意 → “一个月击败发达而和包德利”。
  - 赛珍珠线：青楼出身的赛珍珠求他救她于陈玛丽的刁难，他“明知是火坑也要跳”，手下提醒这可能是发达而的美人计 → “保证赛珍珠不破产击败其他人”；赛珍珠嫌他“小小的成功就知足了”，激他去闯上海 → “积攒 4000 万圆资产”。
  - 上海：弟兄们因他被骗走、生意被抢而散了，部分去充军 → “首先建起别墅”“控制所有娱乐业（全上海夜总会改姓冯）”；他说赛珍珠“侵吞了我大半财产” → “击败赛珍珠”。
  - 结局：“厌倦了商场的尔谀我诈，随即变卖家产，充军去了，据说其作战英勇，屡建战功，还成了抗日英雄。”
- **董莺雨**（溪口镇米号老板的女儿，爱读书，“知识就是财富”）
  - 起点：父亲嫌她读书无用，给 500 万本钱，要她一个月翻一番，不然就嫁人 → “一个月内资产总额达到一千万”；她要自己办书局，“让天下女子都能读书” → “控制所有书局”。
  - 银城：银城码头被外商垄断、米运无利可图，她要去“在商场上和他讨个公道” → “控制所有码头”。
  - 上海：父亲给她三千万作嫁妆，让她爱怎么搞联盟就怎么搞，叮嘱“如若发达，不可骄纵，不可坑害同道”；她说要证明“如今不再是男尊女卑” → “控制上海西区”“三个月击败发达而（与四毛同心合力）”“击败所有对手”。
  - 结局：“成功以后即退出商海，专心于文化事业，创立了《商海周刊》《商汇报》《知识女性》等等著名的报纸刊物。”

可以看到原版的做法：每关的胜利条件都对应主角这一阶段想要的东西（想办书局 → 控制书局，码头被垄断 → 控制码头，被某人欺负 → 击败某人），对手和配角各有立场（金如山贪婪吝啬、发达而傲慢的外商、包德利是投机买办……），关与关之间有“从哪来、到哪去”的线。

**原版文字样例**（取自原版程序，下面这些所属关卡不逐一对应，只看写法和长度）：

- 关前叙述，一段，约 60–120 字：
  - “金县豪绅金如山，依仗其财力，大量收购地产，再高价出租，从中牟取暴利，对其他地主不断排挤，许多商家不堪重负，纷纷破产。四毛本无意经商，只想购地造屋，不想金如山欺其年幼，又恐地产流入他人之手，横加干涉，四毛只能经营金县仅存的几处空地。”（115 字）
  - “四毛听说银城水运发达，船坞码头众多，商家云集，甚是繁华，在银城若是控制水运便财源滚滚，于是变卖家产，一路奔银城而来。”（58 字）
- 对话，每句一两行，约 10–50 字，各角色自己的口吻：

  - “中国的地方，凭啥卖给外国人哩？要运货，交租金。中国人五十万一泊位，外国人一百万一泊位！”（43 字）
  - “终于有了自己的家，不过金如山那老狗也太欺负人了，有机会非整治整治他。”（34 字）

- 战役结局，一段，约 60 字：
  - “四毛凭其聪明才智，虽历经磨难，终由一个流浪儿发展成为上海滩商业巨子。从此扶危济贫、扶助民族工业，成为中国商界的骄傲。”（60 字）

读法：每条战役 6–7 关，前面几关地图小、钱少、目标简单（建一栋旅馆、让某个对手破产），中间换各种目标（控制某行业、控制一片区域、保护同伴不破产、限时建别墅、资产达标），最后一关是完整上海的 5–6 人对局。有的关给玩家比对手少的钱，有的关给某个对手预置地产或多一点存款。

## 三、交给 Claude 的清单

- 必须有：每个角色每一关的表；路人名单（名字、身份，有没有性格 / 台词，要不要头像）；“一个月”是不是 30 天。
- Claude 会：转成关卡数据并校验；需要原版地图的转换并检查企业、连续地块够不够目标用；逐关跑模拟，和作者一起调资金和限时。座位最多 6 个已支持；关前 / 关后对话界面还没做。
- 目标不在条件类型里，或地图企业不够目标用：先说，再决定加条件还是换图。
