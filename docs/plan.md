# 复刻计划

目标：先用 Godot 复刻原版的基础玩法（自由模式 + 角色主线），只做 4 个角色（斐斐、小九、孔雀、理理），每个角色既是可选角色也是 AI 对手。规则先照原版，新规则（`docs/design.md` 的“核心规则”）以后再做。

## 原版规则

已经反汇编查清，见 `docs/original_rules.md`，数值写进了 `data/rules.json` 和 `data/cards/chance.json`。
第 2 步按这套规则实现了，代码在 `scripts/core/game.gd`（用法写在文件开头的注释里），测试在 `tests/game_tests.gd`。

### 第 2 步做了什么

- 回合流程：掷骰前 → 掷两颗骰子 → 一步一步走（路过银行、教堂、遇到别的玩家）→ 停下的效果 → 下一个人。所有人走完一轮 = 一天，每 7 天派息。
- 需要玩家（或 AI）选择的地方，游戏停在 `phase == "pending"`，由画面 / AI 来回答：十字路口选方向（仅 `choice` 路口；`random` 路口自动随机，记 `random_direction` 事件）、路过银行存取款、买地 / 买企业、巡捕房交不交保释金。
- 买地、收租（含企业同行业翻倍、抵押 / 坐牢 / 游览 / 慈善不收租、免费 / 加倍 / 半价状态）、建房 / 升级 / 拆房（含古董和倒塌事件）、税务局、巡捕房、教堂、公园、市政厅（只发特许证）、赛马场（随机名次）、30 张机会卡、状态（小偷、纵火犯、抢劫犯、信徒等）、破产和胜负。
- 发生的事记在 `game.events` 里，第 3 步的画面和台词靠它。
- 随机对局测试：40 局随机玩，每一步检查数据自洽。

### 第 2 步没做（留给后面）

- 抵押、赎回、拍卖、交易：第 5 步。数据结构里已经有 `mortgaged`，抵押中的地不收租、不能建房、总资产按一半算，机会卡 17 也会收走抵押物；但还没有“抵押”这个操作。
- 特许建筑（黑帮、算命铺、当铺）：市政厅现在只发特许证（`player.permit`），还不能建。
- 赛马场：没做小游戏，也没做破纪录奖金。

### 实现时自己定的细节（原版不明或文档没写，可以改）

- 纵火犯停在别人有房子的地上：烧掉整栋房子，这次不收租。
- 升级不触发古董 / 倒塌事件，只有新建房子才触发。
- 日期从第 1 天开始，第 7、14… 天开始时派息（原版是星期六，星期几是假设的）。
- 路过银行（存取款）和路过教堂（捐款）只在“路过”（不是最后一步）时触发；停在银行上原版没有效果，**作者决定改成：停下也能存取款**（存取完这回合结束）。遇到别的玩家（小偷、信徒）连最后一步也算。
- 占 3 块以上地的房子，所占的地上不能有人站着（原版是“门前道路上没有人”，我们的地就在路上）。
- 状态天数在这个玩家每个回合开始时减 1；坐牢 / 游览期间一直算“不收租”，直到下回合开始状态被清掉。
- 坐牢、游览的玩家，路过的人仍然会“遇到”他（小偷、信徒会触发）。
- 机会卡里 5 张带 1940 年代中国背景、“哪个角色能抽到哪张卡”仍然是借用原版角色，见下面“等作者决定的内容”。

### 第 3 步做了什么

- 主界面（`scripts/ui/main.gd`）：4 个位置，每个选人类 / AI / 空，再选角色（同一角色不能坐两个位置，至少 2 人），点“开始游戏”。
- 棋盘画面（`scripts/ui/table.gd`，场景 `scenes/table.tscn`）：画格子、街道色条、地主边框、房子条、棋子、骰子；左边是玩家卡片（现金、存款、总资产、状态、最近一句台词），右边是操作区和日志。点棋盘上的格子看价格、租金、主人。
- 人类操作：掷骰、十字路口选方向、路过银行存取款、买地 / 买企业、交保释金、掷骰前的“房产”对话框（建房 / 升级 / 拆房，鼠标移到按钮上会高亮要占的地）。
- 事件播放：规则每做完一步，画面把 `game.events` 按顺序播放（棋子一步步走、写日志、按 `speech.json` 冒台词）；右上角“快速”可以加快。
- AI：`scripts/core/simple_ai.gd` 是临时的简单 AI（有钱就买、建最贵的买得起的房子、多余现金存银行），第 4 步换成原版的 12 个阈值参数。
- 游戏结束弹出结算，可回主菜单。
- 云端检查：`tools/ui_check.gd` 自动玩一阵并截图（用法写在文件开头）。

### 第 3 步没做

- 抵押、拍卖、交易（第 5 步）；特许建筑；赛马小游戏。
- 骰子没有滚动动画，棋子没有平滑移动（一格一格跳）。美术最后做。
- 台词只用了 `speech.json` 里已有的 12 种事件里能对上规则事件的几种。

2. **不往后放的是第 3.5 步的“拆结构”**（已做）：地图层和界面层分开、等距换算只走一处、图片只走素材路径表。这是技术决定，不用问作者；以后新界面（拍卖、交易、剧情对话、立绘）都建在这个结构上（加在 `table.gd` 的 `_ui` 下面），避免最后重写。
3. **作者测试时只报**：规则对不对、卡不卡、崩不崩、有没有想做却做不了的操作。样子的问题不用报。

   - 角色立绘出场表演、骰子动画、移动动画。
   - 复刻原版底部工具栏：建造、拆除、抵押、赎回、拍卖、交易。
6. 作者在 Windows 上测试和合并；说“合并”时我开 PR。

## 作者对规则的改动（和原版不同，已实现）

- 停在银行格子上也能存取款（原版只有路过才行）。
- **并排的平房可以合并成大房子**（作者记得原版如此，按作者说的做，没有去反汇编核对）：同一条街上并排的自己的平房（中间可以夹自己的空地）直接合并成旅社 / 小洋楼 / 别墅，只付差价 = 新房造价 − 平房造价 × `credit_flat_cost_pct`%（`rules.json` 的 `houses.merge_flats`，默认 100，可关掉）。合并不触发古董和倒塌。建房对话框里是“合并并排的平房”一栏。
- **买下的空地上立一块主人颜色的地主牌**（原版如此）：原版牌子的旗面色号由换色表染成玩家颜色，我们把牌子拆成“不变色部分 + 灰度旗面”两层，画面乘上角色颜色（`assets/placeholder/Sign.png`）。

## 第 3 步测试反馈（作者已测，大致没有 bug）

- 节奏和显示不直观、时机不对：留到最后的“界面与手感”统一调整。
- **地图平衡有问题**：跑了很久四个人平分秋色，没有人拿到连续的地块，没人能建二级建筑（旅馆、花园洋房）。
  - **已用对局验证（第 3.5 步）**：主因是临时 AI 一买到地就立刻盖平房。规则要求旅社 / 洋楼 / 别墅占的必须是自己的**空地**，平房又不能升级成别的，所以地一盖平房就永远凑不成大房子。60 局 4 人打到第 60 天：临时 AI 0 局出现二级以上房子（全是平房）；只改成“同街还能凑大房子时先不盖平房”，56/60 局出现旅馆。
  - 次因是地图和没有交易：两种 AI 下每人最长的连续同主地平均都只有 2 块，所以小洋楼 / 别墅（3–4 块）几乎建不了。原版靠交易（第 5 步）把街凑齐，地图的街也更长。
  - 结论：第 4 步原版 AI 要处理“留地凑大房子”；地图平衡等第 4、5 步做完、接入原版上海地图后再测，现在调 40 格简化图没有意义。
  - 已先改（第 3.5 步）：加了“并排的平房合并成大房子”（见“作者对规则的改动”），平房不再是死路；临时 AI 掷骰前先升级、再合并、再新建。建房对话框里加了“凑大房子”一栏，列出每条街自己有几块、别人有几块、自己的空地最多连着几块、离旅社 / 小洋楼 / 别墅还差什么（作者测试时自己有地却建不了大房子，就是因为地分散在不同的街上）。
- **待办：扒原版各角色（战役）初始地图**：24 张 `.cit` 里有 20 张战役关卡地图（`Sub/Story11–36.cit`，已解析在 `extracted/data/cities/`，关卡说明在 `extracted/text/campaigns.json`），看每个角色开局的地图、初始资金、已有的地产和对手是怎样的，作为换地图和做第 8 步个人主线的依据。

## 第 3.5 步做了什么

- **两层**：`table.gd`（根节点）下面是地图层 `map_view.gd`（格子、房子、棋子，跟着镜头动）和界面层（`CanvasLayer`，玩家卡片、按钮、日志、骰子、对话框，钉在屏幕上）。以后的新界面都加在界面层 `_ui` 下面。
- **等距**：地图 `pos` 还是平面网格坐标，`scripts/ui/iso.gd` 换成 80×40 菱形。画格子、棋子位置、点击判定、镜头目标都只调它；遮挡按“靠后的先画”。
- **路边格**：原版的地在路边，不在路上。画面给每块地（和企业、公共建筑）在直路外侧（远离地图中心）找一格放地基和房子；拐角格（起点、巡捕房等）画在路面上。地图 JSON 里给格子写 `lot: [x, y]` 可以手动指定（以后接原版地图时用）。只影响画面，规则不变。
- **镜头**（`map_camera.gd`）：回合开始平滑移到当前玩家，走动时跟随；鼠标拖动 / 方向键 / WASD 平移，滚轮缩放；右上角“回到当前角色”。镜头对准左右两栏中间空出的那块。
- **占位素材**：`tools/copy_placeholder.py` 从 `extracted/` 挑出地表、道路、地基、格子标记、骰子、4 个走路图，重新拼成小图放进 `fourwinds-benti/assets/placeholder/`（共约 0.5MB，来源见同目录 `README.md`）。画面只通过 `scripts/ui/art.gd` 的素材路径表读图，换素材只改这张表；删掉 `placeholder/` 后画面自动退回色块，不会报错（测试会检查）。走路图占位：外国人→斐斐、黑帮→小九、买办→孔雀、土财主→理理。
- **临时 AI 和建房提示**：见上面“第 3 步测试反馈”的地图平衡一条。街道进度的计算在 `scripts/core/streets.gd`，AI 和界面共用。
- **测试**：`run_tests.gd` 现在在第一帧开始跑（这时全局 `Data` 才有），新增等距换算、素材表的检查，最后把棋盘画面全 AI 跑到第 3 天，确认画面代码能跑（之前无头测试碰不到画面脚本）。

**原来“作者待定”的三个问题，按“样子不用问作者”自己定了，不合适再说：**
- 手动拖过镜头后，这一回合不再自动跟随；下一回合开始或点“回到当前角色”恢复。
- 拖动方式：鼠标拖 + 方向键 / WASD + 滚轮缩放；不做屏幕边缘滚动（容易误触）。
- 完全复刻等距（80×40 菱形，和原版素材对得上）。

**没做（留给“界面与手感”）**：原版 HUD 布局和底部六个按钮、动画（棋子还是一格一格跳，走路图只用第 1 帧，朝向会跟着走的方向变）、立绘气泡、房子用原版建筑图（现在是按级别变高的色块；原版建筑占 2×2 之类的方块，我们的房子沿路排成一行，图要另配）。

## 第 3.5 步之后的建议顺序

1. **3.6 接原版上海地图**（只转这一张）。原版 AI 的参数是按原版地图调的，在 40 格简化图上调 AI 参考价值不大。转换工具写一次，以后战役图和 5–6 张新地图都用它。

3. **第 5 步交易、拍卖、抵押**。做完后**再测地图平衡**：原版靠交易把一条街凑齐，没有交易时测出来的平衡不准。
4. **扒战役初始图放到第 8 步开头**：转换工具能顺带读出 20 张战役图；开局资金、已有地产、对手这些关卡条件到做个人主线时再整理。

## 模型分工（为了省用量）

原则：上一步便宜模型做得不好的地方，主要是没验证就下判断，不是代码写错。所以**要查证、要判断原因、要搭框架的用强的模型；照现成模式、有写好的验收测试的用便宜模型**。交给便宜模型之前，先把要照的模式和验收测试写清楚。拆得太碎也不省：新会话要重新读一遍上下文。

| 步骤 | 用哪个 | 理由 |
|---|---|---|
| 3.6 原版地图转换 | Opus | 要读 `.cit` 的结构，决定地、路口、街道怎么对应到我们的格式 |
| 4 原版 AI | Opus；只有台词交给 Sonnet | 12 个参数原版 `Ai/*.ai` 里已经现成，难的是从反汇编读懂它们怎么用（`getPriceIThink`、`bestSiteToBuild` 等） |
| 5 交易、拍卖、抵押 | 一起用 Opus | 抵押很小，单开会话反而更费；交易、拍卖里 AI 的出价和应对（`tryToTrade`）也要读反汇编 |
| 6 角色生动化 | Sonnet；性格化 AI 用 Opus | 台词和表情主要靠作者定人设 |
| 7 存档 / 读档 | Sonnet | 先写好验收测试：在等待选择（`pending`）时存档，读回后用同样的随机数继续走，结果要和不存档完全一样；浮点数要 `int()` |
| 8 个人主线 | Opus 搭关卡格式和胜负条件，Sonnet 填关卡 | 框架定了以后每关只是填数据 |
| 界面与手感 | Opus 搭统一的提示框 / HUD 框架，Sonnet 做重复的面板 | 先按原版截图搭一版，作者只答“留 / 不要 / 换” |
| 新规则、城市特殊规则 | Opus | 会改动 `game.gd`，不能破坏已有测试 |
| 5–6 张地图 | 用 3.6 的工具转 / 填数据交给 Sonnet；平衡测试用 Opus | 地图本身是数据，`validate_data.py` 兜底；平衡要跑对局、看数据下结论 |

## 等作者决定的内容

- 4 个角色的台词：`data/lines/speech.json` 里是按人设写的草稿，每种事件可以加多句
- 主场城市：斐斐伦敦、理理纽约是建议；小九、孔雀的城市（那不勒斯、巴黎）设计文档里还是待定
- 带 1940 年代中国背景的机会卡（`setting_specific: true`，共 5 张）换皮时要改写

## 省钱省时间的做法

1. 一个会话只做一步，开场说清“做第几步”。
2. `CLAUDE.md` 会被每次会话自动读取，不用重复上传设计文档。
3. 规则逻辑在云端用无头 Godot 测（`tools/setup_godot.sh`）；作者只测画面和手感。
4. 数值都在 `data/*.json`，作者自己改，改完按 F5 看效果。
5. 美术最后做。
6. 模型分工见上面“模型分工”一节。
