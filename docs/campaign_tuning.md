# 怎么自己调主线关卡（不用改代码）

关卡全是数据：`fourwinds-benti/data/campaigns/<角色 id>.json`（`eric` 理理、`david` 斐斐、`marcel` 孔雀、`giorgio` 小九）。改完存盘，在 Godot 里按 F5 重新运行就生效，不用重新导入。写错了主界面底部会显示“数据有 N 个问题”，写着哪一关哪里错。

## 最快的办法：在游戏里临时改

主界面 → 个人主线 → 选角色 → 选关（**所有关都能直接选，不用通关**）→ 简介页：
- **增减对手**：每个对手旁边有“移除这个对手”，最下面选角色点“添加这个对手”（钱默认和你一样，4 个角色用角色 AI、路人用标准 AI，最多 `rules.json` 的 `max_players` 个座位，至少留一个对手）。被移除的对手出现在目标里的条件会自动处理（去掉他、座位号前移；条件没了就补“击败所有对手”）。
- **开局地产 / 企业**：每个座位下面一行写着他开局拥有什么；先在下拉里选一条街或一个行业，再选具体哪一块点“加入这块”，或点“整组加入”（整条街 / 整个行业）；“移除一项…”和“清空”拿走。已经在别人名下的会从别人那里转过来。预置房子要在 json 里写（`house`）。
- 每个人的**现金、存款**直接改数字框；路口可以勾“默认全部随机”，也可以在下面**逐个路口**选“按默认 / 自选 / 随机”（每行写着这个路口的出口通向哪里），点“开始”就用新设置打。这些只对这次运行有效，不写进文件；点“恢复默认”回到文件里的数。
- 简介页下面“复制这一关的数据”会把这一关的 JSON（含你改过的数）复制到剪贴板，想永久改就粘进对应的 json 文件。
- 打完点“重试本关”会沿用你改的数。
- 棋盘上点任意格子，左下角信息里有**编号**（写预置地产要用）。

## 改文件：一关里有什么

一关（`stages` 里的一项）：

| 要改什么 | 改哪里 |
|---|---|
| 对手是谁 | `seats` 里的 `character`。可用：`david` 斐斐、`giorgio` 小九、`marcel` 孔雀、`eric` 理理，路人 `cousin` 堂弟、`passerby_a` 路人甲、`mistress` 情妇（`data/extra_characters.json`）。一关里同一个人只能出现一次 |
| 对手强弱 | `ai`：`new_v2` = 带性格的角色 AI，`standard_v2` = 没有性格的标准 AI（路人默认用后者）。**AI 本身的强弱我会按你的反馈再调**，这里只能换种类 |
| 自己和对手的初始资金 | 每个座位的 `cash`（现金）、`deposit`（存款），单位万圆。不写就用 `rules.json` 的默认（2000 / 2000）。想让谁强就多给谁钱，原版末关常给 Boss 多 1000 存款 |
| 开局已有的地 / 房子 / 企业 | 座位的 `props`：`{"tile": 编号}` 送一块地或一家企业；`{"tiles": [4,5,6,7], "house": "villa"}` 在连续的 4 块地上盖好别墅（`house`：`flat` 平房 1 块、`hotel` 旅社 2、`super_hotel` 旅馆 2、`floor` 小洋楼 3、`super_floor` 花园洋房 3、`villa` 别墅 4；块数要对，必须是同一条街沿路相连的）。**编号要用正格**（见下） |
| 地图 | `map`：地图 id（`python3 tools/map_info.py` 列出所有） |
| 路口方式 | `"crossroad": "random"`（这一关所有路口默认随机，AI 不会被绕圈岔路困住）或 `"choice"`（默认自选）；不写 = 按地图。**单独指定某个路口**：`"crossroads": {"19": "random", "14": "choice"}`（键是路口的格子编号，写不是路口的会报错）。优先级：主界面“路口全部随机”> 单独指定 > 这一关的默认 > 地图。地图上每个路口一直显示“自选 / 随机”和各出口的箭头，点路口格子，左下角写着出口通向哪里 |
| 目标 | `win`（满足任意一条就过关）、`lose`（任意一条就失败，同时满足算失败）。条件类型和写法：`docs/campaigns.md` |
| 限时 | `lose` 里加 `{"type": "days_over", "days": 30}`；不限时就不写 |
| 文字 | `intro` 关前、`outro_win` 胜利后、`outro_lose` 失败后 |

## 地块怎么分布

地块编号、街道、企业都在地图文件里，用这个命令看（会列出每条街有哪几块地、每家企业的编号和行业、路口）：

```bash
python3 tools/map_info.py 地图id
```

例如 `python3 tools/map_info.py london`。想换地块的价格 / 街道，改 `data/maps/<地图 id>.json`（每块地的 `price_pct` 是地价系数，`build_cost_pct` 是建房系数；企业的 `price` / `rent`）。**预置地产写的是“正格”编号**：地图里带 `"site"` 的格子是分身格，不能写。

## 小改地图（调换建筑位置、划街、改路口方向）

地图文件是 `fourwinds-benti/data/maps/<地图 id>.json`。小改用工具 `tools/map_edit.py`（要装 Python），每次改完它会自动检查（格式 + 整张图从任何格子都能走回起点），有问题就**不写文件**并告诉你哪里错。改之前建议复制一份地图文件。先用 `python3 tools/map_info.py 地图id` 或在游戏里点格子看编号。

| 想做什么 | 命令（把 london 换成地图 id） |
|---|---|
| 调换两个建筑 / 地块 / 银行……的位置 | `python3 tools/map_edit.py london swap 12 34`（整个换：名字、行业、价格、类型；只能写正格编号，分身格会自动跟着变） |
| 增加一条街 / 改哪些地属于哪条街 | `python3 tools/map_edit.py london street 新街名 6 7 8`（把这几块地划进“新街名”，不存在就新建，可加 `--color #81c784`；街上最长要有 4 块连续的地才能盖别墅） |
| 街改名 | `python3 tools/map_edit.py london rename-street 旧名 新名` |
| 改某个路口默认自选还是随机 | `python3 tools/map_edit.py london crossroad 19 random`（只改地图默认；关卡里的 `crossroads` 还能再覆盖它） |
| 改路口的方向 / 岔路 | `python3 tools/map_edit.py london exits 19 20 46`（格子 19 走完去 20 或 46，两个以上 = 路口；只写一个 = 单行道）。**改方向容易把图弄成走不通，工具会拦住**；一般是改相邻两格各自的出口，比如把一段路反向 |
| 改价格 / 租金 / 名字 | `python3 tools/map_edit.py london set 4 price=300 rent=60 name=新名字`（能改 price_pct、build_cost_pct、price、rent、name、industry） |
| 只检查 | `python3 tools/map_edit.py london check` |

**做不到的**：新增路面 / 新增地块（要写 `pos` 坐标、`lot` 位置，比较麻烦）；要这类大改就告诉我。

**不用工具、手改 json 也行**：每个格子是 `tiles` 里的一项，`id` 就是下标；`next` 是走完去哪格（两个以上 = 路口，`crossroad` 写 `choice` / `random`）；地写 `group`（街名，要在文件开头的 `groups` 里有）、`price_pct`、`build_cost_pct`；企业写 `industry`、`price`、`rent`；带 `site` 的是分身格（停在上面等于停在它指向的正格上，类型要和正格一致）；`pos` 是路面格的坐标，`lot` 是建筑所在的路边格坐标（决定画在哪）。改完运行 `python3 tools/validate_data.py` 检查。

**改完以后**：关卡里写死的格子编号（预置地产、`crossroads`）如果那个格子换了类型或不再是路口，`validate_data.py` 和主界面的“数据有 N 个问题”会告诉你。

## 几个常用的调法

- **让关卡变简单**：给玩家多一点现金 / 存款；少给对手钱；去掉对手的预置地产；放宽 / 去掉限时；把目标改成“让某个对手破产”这类。
- **让关卡变难**：对手多给钱或预置整条街 / 整个行业（注意：同一个人握同行业的企业越多租金翻得越狠，握 4 家就是 8 倍，踩一次几乎破产）；加限时；目标改成“击败所有对手”。
- **对手太少**：原版每关至少两个对手，一个对手太容易被预测；`seats` 里再加一个座位就行（一关最多 `rules.json` 的 `max_players` 个，现在是 4）。
- **AI 走不到某些格子**：多半是路口把它们引到绕圈的岔路里了，给这一关加 `"crossroad": "random"`。
