# 个人主线：规则框架（给讨论用的 AI）

整份贴给 AI 即可。这里只写游戏**能做什么**和**每关要填什么**，剧情、基调、叙事长短都由作者决定。

## 一、规则框架

**游戏**：大富翁式桌游。玩家轮流掷骰走格子，买地、收租、盖房、交易，现金和存款都付不起账就破产出局。个人主线 = 每个角色一条，每条若干关，每关一张地图、一组对手、一组胜负条件。

**角色**：4 个，斐斐（史德斐）、小九（葛乔玖）、孔雀（杜玛瑟）、理理（任厄理），可当玩家也可当对手，对手 AI 带各自的性格。座位可以超过 4 个，多出来的是“路人”：有没有性格、怎么打、有没有台词、剧情上是什么意义，都由作者定（系统上可用无性格的标准 AI，也可给他一组自己的 AI 参数）。

**一关里能定的**
1. 地图（见下）。
2. 座位：玩家是谁；每个对手是谁（角色或路人）；每人开局现金、存款（单位万圆）。
3. 预置地产：开局谁已有哪几块地、房子、企业（可无）。
4. 胜利条件、失败条件：各是列表，满足任意一条就结束，同时满足算失败。
5. 限时（**可选，不是每关都有**）：按天数的失败条件，一个月暂定 30 天。

**条件类型**（目标只能从这里选，要别的先说，工程上要加）

| 类型 | 说明 |
|---|---|
| 某人破产 | 指定某个对手 / 任意一个 / 全部对手（= 击败所有对手） |
| 建成某种房子 | 谁、哪种（平房 / 旅社 / 旅馆 / 小洋楼 / 花园洋房 / 别墅）、几栋；写成“别人建成”即失败条件 = 首先建成 |
| 控制某行业全部企业 | 如运输（码头 / 火车站 / 电车）、商业、娱乐、纺织、公用、食品、报业 |
| 凑齐一条街 | 指定街或任意一条 |
| 拥有全图 N% 以上的地 | |
| 总资产达到 N | |
| 天数超过 N | 限时用 |

玩家破产默认是失败条件之一。**暂时没有**：保护同伴不破产、联盟 / 背叛、关卡进行中的剧情事件和特殊台词。

**难度只能靠**：对手是谁和几个、开局资金（含让某个对手多一点）、预置地产、限时、地图大小。

**叙事能放的位置**：每关的关前、胜利后、失败后（关卡进行中没有叙事）。形式是一段文字，或逐句对话（`说话人：内容`，可加 `[表情]`，说话人可以是角色、路人或旁白）。长度目前不设限。主线通关后的收尾目前没有位置，需要的话说一声。

## 二、参考：原版战役是什么样的（不是我们的角色）

原版《上海大富翁 1940》三条战役共 20 关（四毛 7、冯全篾 7、董莺雨 6）。每关有：地点、出场人物、胜利 / 失败条件、开局数字、一段关前叙述、几句对话；通关后有一段结局文字。

- **结构**：前 1–2 关在小镇（开局 200–500）：建一栋旅馆、让某个对手破产；中段换各种目标（控制码头 / 书局 / 娱乐业、控制一片区域、保护同伴不破产、限时建别墅、资产达标）；末关是完整上海 5–6 人（开局 2000 左右）：击败所有对手或击败某个 Boss（Boss 常多 1000 存款）。
- **难度杠杆**：对手多少和强弱、开局资金不对称（有的关玩家比对手穷）、预置地产（某对手开局有房子）、限时。
- **限时**：20 关里只有 5 关有（一个月 3、三个月 2），其余失败条件只有破产，或指定的人破产 / 没有首先达成目标。
- **每关胜利条件对应主角当时想要的东西**：想办书局 → 控制书局；码头被外商垄断 → 控制码头；被人欺负 → 击败那个人。

**三位主角（原版）**
- **四毛**：流浪儿，拾荒得古董后想置地安家，被金县豪绅金如山排挤 → 去银城夺回被外商发达而垄断的码头，与董莺雨结成民族商业联盟 → 到上海整垮发达而、称霸上海滩。结局：成为上海滩商业巨子，扶危济贫、扶助民族工业。
- **冯全篾**：元宝山黑帮老大，豪爽、喜欢投资。去金县投资被金如山挡住，怒而整倒他 → 回元宝山对付抢生意的买办包德利和发达而 → 赛珍珠求助（可能是美人计），后来他在上海被她侵吞财产，要击败她。结局：厌倦商场，变卖家产充军，成了抗日英雄。
- **董莺雨**：溪口镇米号老板之女，爱读书，“知识就是财富”。父亲给本钱要她一个月翻番，否则嫁人 → 要办书局让天下女子读书 → 去银城与垄断码头的外商讨公道 → 去上海证明“不再是男尊女卑”。结局：成功后退出商海，创办报纸刊物。

**其余角色（原版介绍摘要）**：发达而，美商船运职员，狂妄自大、财大气粗；包德利，洋行买办、投机专家；金如山，金县大财主，极端贪婪吝啬、精于算计；陈玛丽，纱厂富商之女，任性、挥金如土；赛珍珠，青楼出身、赎身后成了交际花。

**文字长度样例**：关前叙述约 60–120 字一段（例：“四毛听说银城水运发达，船坞码头众多，商家云集，甚是繁华，在银城若是控制水运便财源滚滚，于是变卖家产，一路奔银城而来。”）；对话每句 10–50 字（例：“中国的地方，凭啥卖给外国人哩？要运货，交租金。中国人五十万一泊位，外国人一百万一泊位！”）；战役结局约 60 字一段。

## 三、每关要填的

| 项 | 内容 |
|---|---|
| 关卡名 | |
| 地图 | 大小 + 企业要求（或具体地图） |
| 玩家 | 哪个角色；开局现金 / 存款 |
| 对手 | 每个：角色或路人；开局现金 / 存款；预置地产 |
| 胜利 / 失败条件 | 从上面选，可多条 |
| 限时 | 天数，或“无” |
| 关前 / 胜利后 / 失败后 | 文字或对话 |
| 想要的难度感觉 | 可选，具体数字之后由 Claude 跑模拟标定 |

没想好的写“待定”。

## 四、交给 Claude 的清单

必须有：每个角色每一关的表；路人名单（名字、身份，有没有性格 / 台词，要不要头像）；“一个月”是不是 30 天。Claude 会把表转成关卡数据、选图转图、逐关跑模拟标定。座位最多 6 个已经支持；“关前 / 关后对话界面”还没做，现在只有一段文字。目标不在条件类型里或地图企业不够：先说，再决定加条件还是换图。
