# 个人主线：给讨论用的规则框架

整份贴给讨论用的 AI 即可，不用另附文件。这里只写游戏**能做什么**、每关**要填什么**，剧情、基调、叙事长短都由作者决定，这份文档不替作者定。

## 一、规则框架

**游戏**：大富翁式桌游，2 个以上玩家轮流掷骰走格子，买地、收租、盖房、交易，破产出局。单位万圆。个人主线 = 每个角色一条，每条若干关，每关一张地图、一组对手、一组胜负条件。

**角色**（4 个，可当玩家也可当对手）：斐斐（史德斐）、小九（葛乔玖）、孔雀（杜玛瑟）、理理（任厄理）。对手用带性格的角色 AI。超过 4 个座位时，多出来的是“路人”：只有名字，用没有性格的标准 AI，不说台词。路人名单由作者给。

**一关里能定的东西**

1. 地图：从下面的地图目录里选一张。
2. 座位：玩家是哪个角色；每个对手是谁（角色或路人）；每个座位的开局现金、存款。
3. 预置地产：开局谁已经有哪几块地、哪些房子、哪些企业（不写就是都没有）。
4. 胜利条件、失败条件：各是一个列表，**满足任意一条就结束**；同时满足时算失败。
5. 限时：按天数（一天 = 所有人各走一次），“一个月”暂定 30 天。

**条件类型**（目标只能从这里选；要别的要先说，工程上要加）

| 类型 | 意思 |
|---|---|
| 某人破产 | 指定某个对手，或“所有对手全部破产”（= 击败所有对手），或“任意一个” |
| 建成某种房子 | 谁、哪种房子（平房 / 旅社 / 旅馆 / 小洋楼 / 花园洋房 / 别墅）、几栋。写成别人建成就是失败条件，即“首先建成” |
| 控制某行业全部企业 | 行业见地图目录 |
| 凑齐一条街 | 指定街，或任意一条 |
| 拥有全图 N% 以上的地 | |
| 总资产达到 N | |
| 天数超过 N | 一般写在失败条件里 |

玩家破产默认是失败条件之一。**暂时没有**：保护同伴不破产、联盟 / 背叛、关卡进行中的剧情事件和特殊台词。

**难度只能靠这些调**：对手是谁和几个、开局资金（含让某个对手多一点）、预置地产、限时、地图大小。

**叙事能放的位置**（关卡进行中没有叙事）

- 每关：关前、胜利后、失败后。
- 形式：一段文字，或逐句对话。对话每句是 `说话人：内容`，句尾可加 `[表情]`（平常 / 开心 / 生气 / 得意 / 沮丧 / 惊讶 / 无奈），说话人是角色、路人名字或“旁白”。
- 长度：目前不设限，界面还没做，以后按显示效果调整。
- 主线通关后的收尾：目前没有位置，需要的话说一声，工程上加。

## 二、每关要填的

| 项 | 内容 |
|---|---|
| 关卡名 | |
| 地图 | 地图目录里的原版文件名，或 shanghai_loop |
| 玩家 | 哪个角色；开局现金 / 存款 |
| 对手 | 每个：角色或路人名字；开局现金 / 存款；预置地产（几块、哪条街、有没有房子） |
| 胜利条件 | 从上面的条件类型选，可多条 |
| 失败条件 | 同上 |
| 限时 | 天数，没有写“无” |
| 关前 / 胜利后 / 失败后 | 文字或对话（格式见上） |
| 想要的难度感觉 | 可选。我会逐关跑模拟标定具体数字，你写的数当起点 |

没想好的写“待定”。

## 三、交给 Claude 的清单

- 必须有：每个角色每一关的表；路人名单（名字，要不要头像）；“一个月”是不是 30 天。
- Claude 做 8b 时：转成关卡数据并校验；需要原版地图的转换并检查企业、连续地块够不够目标用；先加**关前 / 关后对话界面**和**超过 4 个座位**两个功能（还没做）；再逐关跑模拟，和作者一起调资金和限时。
- 目标不在条件类型里，或地图企业不够目标用：先说，再决定加条件还是换图。
