# 个人主线：和其他 AI 讨论剧情用的简报

用法：把“一、给 AI 的背景”整段贴给讨论用的 AI（再附上 `fourwinds-benti/data/characters.json` 和 `docs/design.md` 里的角色 / 世界观部分），然后照“二、让它产出的格式”要结果。讨论完把“三、交给 Claude 的清单”里的东西发给 Claude，Claude 就能做 8b（填关卡）。

---

## 一、给 AI 的背景（可整段贴）

**项目**：《四方来财》，大富翁式桌面游戏（复刻 1998 年《上海大富翁 1940》的玩法，换成原创角色）。要给 4 个可选角色各写一条“个人主线”，每条 3–4 关，每关有不同的对手和胜利目标，结局搞笑。

**玩法最小规则**（足够设计目标，不用懂细节）：
- 2 到 4 个玩家（主线里可以更多，见下）轮流掷两颗骰子，沿路走格子。停在无主的地上可以买；停在别人的地上付租金。一圈一天。
- 同一条街沿路连续的地，自己有几块就可以盖多大的房子：平房（1 块）、旅社 / 旅馆（2 块）、小洋楼 / 花园洋房（3 块）、别墅（4 块）。别墅租金最高。
- 企业（码头、火车站、电车、百货、夜总会、织厂、报馆、公用事业等）按行业分组，同一个人拥有同行业越多，租金翻得越多。
- 有银行（存款每 7 天派息）、机会卡、监狱、教堂等。可以抵押、交易、拍卖。
- **破产 = 现金加存款都付不起账**，资产全部给债主。破产的人出局。
- 单位：万圆。原版战役里的数字：开局现金 + 存款，小镇关 200–500、银城关 1000、上海关 1500–2000。

**角色**（都既可以是玩家也可以是 AI 对手；对手用“角色 AI”，也就是带性格的 AI，所以角色性格会体现在对手怎么玩上）：

| 角色 | 身份 | 说话风格 | 玩法性格 |
|---|---|---|---|
| 斐斐（史德斐） | 英国犹太银行世家 | 客气、冷静，全是银行和账本的说法 | 冷静估价，谈判时让对方先开口 |
| 小九（葛乔玖） | 那不勒斯走私商 | 热情、夹意大利语，讲义气，满口“朋友” | 讲义气，对某个玩家特别好说话 |
| 孔雀（杜玛瑟） | 巴黎教授，吐火罗语专家 | 文绉绉、爱面子，动不动搬出学术头衔 | 精明但爱面子，喜欢某几条街 |
| 理理（任厄理） | 德裔美国政客、投资人 | 政客腔，永远“早就料到”，什么都推给对手 | 永远比你快半步，爱纠缠着交易 |

每个角色通关自己的主线后解锁“里形态”（更难的版本，剧情上可以是这个人的另一面 / 黑历史）。里形态的名字和身份还没定，**主线剧情可以给它铺垫，但不要依赖具体设定**。

**一关能表达的东西**（目标只能从这里选；想要别的目标要先说，工程上要加）：

| 目标类型 | 例子 |
|---|---|
| 击败指定对手（让他破产） | 让金如山破产 |
| 击败所有对手 | 经典终局 |
| 建成某种房子（首先 / 在限时内） | 一个月内建成一栋别墅；首先建成别墅 |
| 控制某个行业的全部企业 | 控制所有码头 / 书局 / 娱乐业 |
| 凑齐一条街 | 买下整条某某路 |
| 拥有全图 N% 以上的地 | 控制整个西区 |
| 总资产达到 N | 积攒 4000 万资产 |
| 限时 | 超过 N 天算失败 |
| 失败条件 | 玩家破产（几乎每关都有）、超时、**别人先达成某目标**（例如别人先建成别墅） |

多个胜利条件之间是“或”（满足任意一条就过关）。**暂时没有**：保护同伴不破产、背叛 / 联盟、对手中途换人、关卡中途剧情事件。

**一关能调的难度杠杆**（照原版，不加新机制）：
1. 对手有几个、是谁（对手是角色 AI，每个角色打法不同）。
2. 开局资金不对称：玩家比对手穷或富；末关常给 Boss 多一点存款。
3. 预置地产：开局谁已经有几块地、几栋房子、几家企业。
4. 限时天数。
5. 选哪张地图（地图越大越慢：见下表）。

**地图**（每关选一张；还有别的原版地图可以转，转换由工程做）：

| 地图 | 格数 | 企业 | 备注 |
|---|---|---|---|
| 一圈（shanghai_loop） | 40 | 运输 2 / 娱乐 2 / 商店 1 | 最小，路是一圈，没有岔路 |
| 上海西区（shanghai_west） | 85 | 公用 4 | 有 3 个路口 |
| 上海（shanghai） | 160 | 运输 / 娱乐 / 商店 / 织厂 各 4 | 完整大图，7 个路口，一局常打 100 天以上 |
| 金县（原版第 1 关图） | 约 32 | 无（一张图有 3 家食品） | 小镇，教学 |
| 元宝山 / 金县二（原版） | 约 32–50 | 3 家食品 | |
| 溪口镇（原版） | 约 32–50 | 1 家码头；或 1 码头 + 3 报馆 | |
| 银城（原版） | 约 80 | 4 个码头 + 1 食品 | |
| 上海闸北（原版） | 约 80 | 2 火车站 + 2 电车 | |
| 上海局部（原版） | 约 119 | 12 家 | |

> 目标要和地图对得上：例如“控制所有码头”需要地图上有足够多的码头；小镇图上没有几家企业，就不适合“控制某行业”。选图时看上表的企业一栏。

**限制**：
- 关前的剧情用**对话**（几句话一屏，谁说的 + 内容）传达，关卡进行中不会有特殊台词、不会有剧情事件。所以关卡的剧情只能靠：关前对话、关后（胜 / 负）对话、对手是谁、目标是什么。
- 关卡里的角色用 4 个角色之一；超过 4 个座位时多出来的是“路人”（见三）。
- 不要写依赖新规则的目标（例如“让某人欠你钱”“偷走某张卡”）。

**风格**：这是 OC 游戏，重点是展示角色性格，结局搞笑。难度要有起伏：前面的关让人学会、中间换花样、最后一关是考验。

## 二、让它产出的格式（每个角色一份）

**主线名**：（一句话）

**每关一张表**，照下面填（没想好的写“待定”，不要硬编）：

| 项 | 内容 |
|---|---|
| 关卡名 | |
| 地图 | 上表里选一张 |
| 玩家（你） | 就是这个角色；开局现金 / 存款 |
| 对手 | 每个对手：是谁（4 个角色之一，或路人）、开局现金 / 存款、**预置地产**（几块、在哪条街、有没有房子，不写就是什么都没有） |
| 胜利条件 | 从“一关能表达的东西”里选，可以多条（“或”） |
| 失败条件 | 同上；玩家破产默认有 |
| 限时 | 几天（一个月 = 30 天，暂定） |
| 关前对话 | 见下 |
| 胜利后对话 | |
| 失败后对话 | |
| 难度意图 | 这一关想让玩家感觉什么（轻松 / 要小心某个对手 / 时间很紧……），Claude 之后会跑模拟标定数字 |
| 笑点 / 备注 | |

**对话格式**（每句一行）：

```
斐斐：我的账本上没有“失败”这一项。[得意]
旁白：三天后，银行门口排起了长队。
金如山（路人）：喂，你是谁？
```

说话人是 4 个角色之一、路人名字，或“旁白”；句尾方括号是表情（平常 / 开心 / 生气 / 得意 / 沮丧 / 惊讶 / 无奈），可省略。

**还要给的**：
- 一条主线通关时的**总结局**（搞笑）。
- 里形态解锁的一句话铺垫（可选）。

## 三、交给 Claude 的清单（做 8b 前要有的）

必须有：
1. 每个角色的每一关表（上面第二部分的格式）。
2. **路人名单**：名字、一句话身份、说话风格。路人用标准 AI（没有性格）打，没有台词，只在对话里出现。如果要给路人配头像，说明用原版哪张占位。
3. 确认“一个月”是多少天（暂定 30 天；作者觉得原版大地图一局常 100 天，小地图再看）。

可以晚点给（我会先按默认做，之后改）：
- 对手的 AI 类型（默认全是角色 AI；路人是标准 AI）。
- 每关的难度细节：写意图就行，**具体的开局资金和限时由 Claude 逐关跑模拟标定**，你给的数字当作起点。

Claude 做 8b 时会自己做的：
- 把表转成 `data/campaigns/<角色>.json`，校验能过。
- 需要原版地图的，用转换工具转进来并检查企业数量、连续地块够不够目标用。
- 加两个小功能（还没做）：**关前 / 关后对话界面**（照上面的对话格式逐句显示，带头像）和**超过 4 个座位**（路人座位、玩家卡片放得下 6 个人）。这两个做完才能看到完整的关卡流程。
- 逐关跑 AI 对战模拟，看目标能不能达成、要多久，回头和你一起调资金和限时。

做不到 / 要先问你的：
- 想要的目标不在“一关能表达的东西”里（比如保护同伴不破产）：要先加条件类型。
- 地图上企业不够目标用：换图或改目标。
